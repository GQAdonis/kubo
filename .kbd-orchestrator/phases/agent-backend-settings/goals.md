# Goals

- Runtime settings UI for the agent backend in BOTH IPFS Desktop (macOS arm64) and the Web UI served from the cloud node (https://ipfs.prometheusags.ai), replacing config-file-only setup; saving applies without a manual restart
- Backend option 1, Universal Agent Runtime (UAR): point at a UAR instance, create an IPFS agent on it (own system prompt, the kubo MCP tools, the IPFS agent skills) and chat through that agent; code at ~/Projects/prometheus/universal-agent-runtime (our code; prior deferral tracked in Prometheus-AGS/universal-agent-runtime#379)
- Backend option 2, OpenAI-compatible endpoint (e.g. liter-llm): a Go proxy in this kubo codebase, started like ipfs mcp, that serves AG-UI plus the A2UI control registry and forwards to the OpenAI-compatible endpoint (build on the existing ipfs mcp --agui bounded agent loop rather than duplicating it)
- Agent features on by default per AGENTS.md 5f019f0df (Desktop starts the local endpoint, chat on, WebMCP on, Desktop confirmation window on); every feature keeps an off switch; writes still require confirmation; no third-party backend chosen for the operator
- Rebrand the entire fork Web UI (every route, the agent chat, settings, favicon/manifest, title and copy) to Promethity branding from `/Users/gqadonis/Projects/promethity` (`branding/`, `docs/`, `publish/`); keep IPFS attribution and license notices. UI built by the team's ui-ux-engineer using the impeccable, ui-ux-pro-max and vercel-react-best-practices / vercel-composition-patterns skills (operator direction 2026-10-13)
- Vector search over the files on the node, on both the LKE cloud node and IPFS Desktop (macOS arm64): text and Markdown, PDF and Office documents, source code and JSON/CSV through upstream xberg (`xberg-io/xberg`, latest release, run as a service), and images and video through descriptions from an operator-configured vision model (Xiaomi MiMo-V2.6 or another OpenAI-compatible endpoint) embedded like any other text; files the operator pins or keeps in MFS are indexed by operator-started, capped, resumable bulk runs that add, pin and announce nothing; the embedder, extractor, describer and store hosts are operator-configured with no defaults and covered by `egress_ack` unless loopback; GQAdonis/liter-llm is an optional gateway; search from agent chat and MCP clients and from a search page in the Web UI; every part off unless configured, with an off switch, docs and a disabled-state test (operator direction 2026-10-14; ADR-0011)
