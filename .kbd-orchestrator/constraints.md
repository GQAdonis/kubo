# KBD Constraints — Kubo

Generated by `/kbd-init` on 2026-10-09 from `AGENTS.md` (Stability, User Agency, Building, Testing, Scope and Safety) and the `kubo-ipfs-agentic` team ownership. `AGENTS.md` remains authoritative; if this file and `AGENTS.md` disagree, `AGENTS.md` wins and this file is regenerated.

Command policy (from `AGENTS.md`), applied to every command below:

- Build with `make build`, never `go build`.
- Integration tests (`test/cli`) require `make build` first, then `PATH="$PWD/cmd/ipfs:$PATH"` and an isolated `IPFS_PATH`. Every `test/cli` command below carries that prefix.
- Dependency changes go through `go get` plus `make mod_tidy` (root, `docs/examples/kubo-as-a-library`, `test/dependencies`).
- Do not run `make test` or `make test_sharness` unless asked.

Path ownership exceptions: `.agent-team/`, `.prometheus/`, `.kbd-orchestrator/`, `.agents/`, `.claude/`, `.codex/`, `.kimi-code/`, `.opencode/` and `openspec/` are deliberately tracked tool and team state, not disposable. `.agents/skills/` holds vendored third-party skills recorded in `.agents/skills/VENDORED.md`.
