## 1. Tasks

- [x] 1.1 Route `#/search` in `src/bundles/routes.js` and one navigation entry, shown only when `GET /index/status` answers with a configured index; the client takes the endpoint and token from the same source as the agent chat (`src/agent-chat/endpoint.js` and the bridge on Desktop; on the console, the chat's `ui` token), adds no new token storage, and sends nothing when the route is absent. Acceptance: Jest tests show the entry hidden for 404, `not_configured` and network failure, and shown for a configured status; no new `localStorage` key holds a token.
- [x] 1.2 Search page in `src/search/`: query box, kind filter chips from the contract's content kinds, results with file name or path, CID with copy, kind, a provenance label ("From the file" for `text` and `extracted`, "Text in image" for `ocr`, "Transcript", "AI description by <model>" for `description`), score and snippet, and actions to open the hit in Files or Explore. Snippets and labels render as text only, never as HTML or Markdown. Acceptance: Jest tests render each provenance label, and a snippet containing `<img src=x onerror=alert(1)>` renders literally with no element created.
- [x] 1.3 Index status panel (read-only): the indexed total, the last bulk run's status, counts and skip reasons, and a line telling the operator to start or resume a run from the agent chat ("Ask the agent to index your pinned files"); no button starts a run. Acceptance: tests render the not-configured, idle, running, paused and failed states.
- [x] 1.4 Errors: `egress_not_acknowledged` shows the hosts and links to the setup docs; `index_unavailable` offers retry; 401 asks to sign in again as the chat does; 403 explains the token lacks search access. Acceptance: one test per error state.
- [x] 1.5 Styling and accessibility with the Promethity foundation and primitives: labelled search input, keyboard-operable filters and results, visible focus, a live region announcing result counts; strings in `public/locales/en/` only. Acceptance: no hard-coded colors outside the token layer (grep); the axe run at `phase-integration-gate` lists the page.
- [x] 1.6 Off switch: a Web UI setting `search.enabled` (default on, effective only when the backend reports a configured index) hides the route and the nav entry, and the page makes no request when it is off. Acceptance: a disabled-state test asserts no navigation entry, a redirect from `#/search`, and zero fetches to `/index/*`.
- [x] 1.7 Playwright spec `test/e2e/search.test.js` against a stub `ipfs mcp` that serves fixed `/index/status` and `/index/search` responses: search, filter, open a hit in Files, and the disabled state. Acceptance: the spec exists and is listed for the gate; it uses no real embedder.
