## 1. Tasks

- [ ] 1.1 Image describer client: `POST <describer.base_url>/chat/completions` with `model`, the contract's fixed instruction, and the image as an `image_url` part carrying a base64 `data:` URL (never an `http(s)` URL that points at the node or a gateway); `max_output_tokens`, `timeout_seconds`, `image_max_bytes` checked before the request is built, and `max_requests_per_hour` enforced across all callers (`0` disables the describer). The response is validated as untrusted input. Acceptance: unit tests against an `httptest` fake assert the request shape (a `data:` URL, no node or gateway URL anywhere in the body), the byte cap (zero requests for an oversize image) and the hourly limit.
- [ ] 1.2 Video: only when `describer.kinds` includes `video`, send a `video_url` part with a base64 `data:` URL, `fps` from `video_fps` and `media_resolution: "default"`, within `video_max_bytes`. When `extractor.transcribe` is on, the audio transcript from the extractor is indexed as `source: transcript` whether or not video description is on. A describer that rejects or drops the video part (for example a gateway without `video_url` support) makes the stage fail with a warning on the file, not the whole file. Acceptance: tests for the request shape, the cap, a video skipped when `kinds` is `["image"]`, and a rejected video part recorded as a stage failure while the transcript is still indexed.
- [ ] 1.3 Store descriptions as chunks with `source: description`, `described_by: <model>`, `kind`, `mime_type` and the chunk text; `ipfs_index_cid` with `force` replaces a file's description entries. Acceptance: tests for the stored fields and for replacement on `force`.
- [ ] 1.4 Egress: the describer host joins the host set checked against the calling principal's `egress_ack`; a loopback describer is covered by `local`. A refused describer stage sends nothing; OCR and transcript stages of the same file still run. Acceptance: with the describer host absent from `egress_ack`, the fake describer receives zero requests and the file result names the host.
- [ ] 1.5 Real-service test against an operator-configured describer named by environment (`IPFS_MCP_TEST_DESCRIBER_URL`, `..._MODEL`, and the name of the variable that holds the key): describe one PNG fixture and find it by a word from its description; video only if OG-17 approved a hosted video describer. It skips with a named reason when the variables are unset. Acceptance: the test exists and runs at `phase-integration-gate`; the evidence names the describer host and whether it was hosted.
- [ ] 1.6 Disabled states: with no `describer` block, images and videos are skipped `describer_not_configured` unless OCR or transcription covers them, and no describer request is made; with `kinds: []` or `max_requests_per_hour: 0` nothing is described. Acceptance: unit tests and `TestMCPDescriberDisabled` in `test/cli/`.
- [ ] 1.7 Untrusted content: description hits carry the same untrusted-content marking as other search hits in tool output and in the agent loop, and `described_by` is always present on them. Acceptance: a test asserts the marking and the field on a description hit returned by `ipfs_index_search`.
