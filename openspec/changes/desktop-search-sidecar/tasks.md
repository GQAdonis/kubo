## 1. Tasks

- [ ] 1.1 Verify `xberg-cli-aarch64-apple-darwin.tar.gz` from the `xberg-io/xberg` `v1.3.10` release on macOS arm64 and record commands and output: SHA-256 against the release, Gatekeeper and quarantine behavior when launched as a child of Electron, `xberg --version`, the `serve` flags found in `mcp-content-extractor` 1.1, the default cache path and whether the offline mechanism works. Nothing is installed system-wide; the binary is unpacked into a scratch directory. Acceptance: the findings are saved in the evidence folder the lead names, and any blocker (for example quarantine refusing to run) is stated with its workaround or as open.
- [ ] 1.2 Sidecar config generation in `src/daemon/mcp-sidecar*.js`: when the Search setting is on and absolute paths to an operator-installed `surreal` and `xberg` and an embedder URL, model and dimensions are set, write an `embeddings` block in embedded mode for both (data and cache directories under Desktop's userData), `bulk` and `search_route` at their contract defaults, and the describer only if the operator configured one; with Search off, or a path missing or not executable, write no `embeddings` block and surface the reason. No `PATH` lookup, no download. Acceptance: tests generate the config for on, off, a missing binary and a non-executable binary, and assert no network call is made by the generator.
- [ ] 1.3 Egress: the Desktop `ui` principal's `egress_ack` gets `local` when every configured host is loopback; a non-loopback embedder or describer host is added only after a dialog that names the host and states that file content goes to it, confirmed with Touch ID as D4 does for the chat backend; removing the host or turning Search off removes the entry. Acceptance: tests for the loopback case, a refused confirmation (no entry written), an accepted one (exactly that host added), and removal.
- [ ] 1.4 Restart semantics: a change to any search setting restarts the `ipfs mcp` sidecar (embedding settings are not hot-reloaded, ADR-0011 V6); a bulk run in progress ends up `paused`, and the status shown to the user says so. Acceptance: a test drives a settings change and asserts one sidecar restart and the reported `paused` state.
- [ ] 1.5 Desktop settings UI in `src/agent/`: a Search section, off by default, with binary path pickers for `surreal` and `xberg`, embedder URL, model and dimensions, an optional describer with a visible warning when its host is not loopback ("file bytes are sent to <host>"; "video description needs a hosted model"), and a note on CPU and disk use. Acceptance: tests show the section off on a fresh profile and each warning when its condition holds.
- [ ] 1.6 Disabled state: with Search off (the default), no `surreal` or `xberg` process runs, the generated `ipfs mcp` config has no `embeddings` section, and the Web UI search navigation entry is hidden because `/index/status` answers 404. Acceptance: a test in `test/` asserts all three on a fresh profile.
