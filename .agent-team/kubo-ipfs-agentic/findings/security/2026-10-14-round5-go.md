# Security findings: agent-backend-settings Round 5 (Go: mcp-media-describer, mcp-whole-node-indexing)

Reviewer: `security-reviewer` (Claude Opus, separate context). Date: 2026-10-14. Static reading only. Written to disk by the lead from the returned report. H1 confirmed by the lead: `filesLsCmd` uses `cmdenv.GetNode`, `mfs.Lookup` and `fsn.List` (`core/commands/files.go:719-756`), so the global `offline` option (applied only in `GetApi`) does not apply; `mcp/server/index_bulk.go:358` relies on it.

**Verdict: FAIL** (H1). Expected PASS WITH FINDINGS once H1 is fixed with a real-daemon test. Also 2 MEDIUM, 6 LOW, 4 INFO.

## Threat model delta

Long-running bulk walk over pins and MFS as the starting principal, sending local files to the embedder, remote store, remote extractor and describer; media to an OpenAI-compatible describer whose answers become searchable text (prompt-injection carrier); new `POST /index/search` and `GET /index/status`; server-built confirmation summary.

## HIGH

- **H1. The MFS walk is not offline.** `index_bulk.go:358` calls `files/ls` with `offline: true`, which Kubo ignores; with `long`, `fsn.List` loads children through the online DAG service and `mfs.Lookup` lazy-loads path components, so lazily copied MFS directories and HAMT shards are fetched over bitswap. Other reads are offline (`files/stat` on `/ipfs/` via `api.ResolveNode`, `ls` and `cat` via `GetApi`). Scenario: operator imports a third-party directory by `files cp /ipfs/<cid>`; a default bulk run broadcasts wantlist entries, stores fetched blocks (possibly provides them, unverified), indexes small fetched files, and can hang in `running` on an unavailable block (no deadline, `index_bulk.go:118`). Breaks `docs/mcp/embeddings.md:378` and tasks 1.1/1.4; the unit test checks the option was sent, and `TestMCPBulkIndexNoInjection` uses only local content. Fix: resolve the MFS root once with `files/stat --hash /`, walk `/ipfs/<rootcid>/<relative mfs_root>` with offline `ls` and offline `files/stat`, keep the MFS path as cursor, skip unreadable as `not_local`; per-RPC timeouts (L2); a `test/cli` case with a lazily copied non-local CID asserting `refs local` unchanged and a `not_local` skip; update `embeddings.md:385`.

## MEDIUM

- **M1. Resume ignores a narrowed `bulk.sources` and `mfs_root`.** `index_bulk_tools.go:300-315` keeps stored `Sources` and `MFSRoot` though `planFor` (`:155-157`) promises never to leave config. Fix: intersect with `cfg.EffectiveSources()` (refuse `failed_precondition` if empty); refuse a stored root outside `cfg.EffectiveMFSRoot()`; mirror in `storedRunForSummary`.
- **M2. `ipfs_index_search` accepts and ignores `kinds`/`sources`.** Schema `ipfs_index_search.input.json:22-54`; `indexSearchInput` (`index.go:144-148`) lacks them; same handler serves `/index/search` (`index_routes.go:160`). A filter meant to exclude `description` (prompt-injection carrier) is silently dropped. Fix: implement in the store query or over-fetch and post-filter; until then refuse non-empty filters with `invalid_argument`; test `sources: ["text"]` returns no description hit.

## LOW

- **L1.** No rate or concurrency limit on `POST /index/search` (`index_routes.go:131-166`); MCP-03. Fix: per-identity token bucket with 429 `Retry-After`, small concurrency cap.
- **L2.** Bulk run RPC calls have no per-call deadline (`index_bulk.go:118`, `:264`, `:306`, `:313`, `:358`, cat calls in `index_file.go`). Fix: `context.WithTimeout` per call.
- **L3.** Waiting on the describer hourly limit re-sends media to the extractor and starves interactive calls (`index_bulk.go:495-512`; `index_file.go:347-359`, `:373-376`). Fix: check `Describer().RetryAfter()` before any stage in a bulk run, or keep the extractor result; optionally reserve budget for interactive calls. Waiting rather than skipping is acceptable.
- **L4.** Read paths write run state without the bulk lock (`index_bulk_tools.go:324-339`, `index_routes.go:215-227`, `:104-107`). Fix: pause transitions only in `recoverBulkRun` and start/cancel; status read-only.
- **L5.** Stage warnings in `_meta` carry endpoint-supplied text on tools not marked untrusted (`index_file.go:289`, `:401-403`, `:413-416`; `describer.go:439-453`). Fix: stage plus fixed reason code in `_meta`, endpoint text to the log only (or mark untrusted). The `_meta` key itself is acceptable; add to the contract once fixed.
- **L6.** `--print-rpc-allowed-paths` lists bulk paths with no embeddings section (`cmd/ipfs/kubo/mcp_http.go:136-140`, `rpcpaths.go:41-47`). Fix: disable all index tools when `cfg.Embeddings == nil`.

## INFO

- **I1.** Description text keeps bidi and control characters (`describer.go:462-477`); clients must render as plain text (`routes/index.json:47`).
- **I2.** Describer client honours `HTTP(S)_PROXY` (`describer.go:226-234`), same as embedder and extractor; document or set `Proxy: nil`.
- **I3.** Any index principal sees others' `started_by`/`last_error` and can cancel others' runs with confirmation (`index_bulk_tools.go:82-88`, `index_routes.go:208-210`); document for single-operator nodes.
- **I4.** `describer_not_configured` vs `kind_not_enabled` choice acceptable (allowlist gates first, `index_file.go:244-252`, `:421-424`); describer failures as `extraction_failed` acceptable (`:327-331`); a contract reason `description_failed` would be clearer.

## Verified controls

No CID injection on the pin path (only `pin/ls`, offline `files/stat`, offline `ls`, offline `cat`; no add/pin/write/provide); caps real (min of input and config, re-clamped on resume, checked before each read, paced, defaults 1000 files / 1 GiB / 30 per minute); no start without write-class confirmation and egress coverage for every stage host, re-checked at start and per file, operator identity covers nothing; restart leaves the run paused and nothing resumes without `resume: true` and a fresh confirmation; `argsHash` from raw arguments, summary display-only with clamped values and every non-loopback host; describer off by default, https for non-loopback, base64 data URLs only, size cap before build, egress before budget, shared hourly limit, no redirects, bounded validated response, key only in the Authorization header, fixed prompt; untrusted marking and `described_by` on hits; routes with Host/Origin/fetch-metadata checks, body limit, strict CORS without credentials, kind and group checks, schema validation, `callTimeout`, absent when disabled; path handling filtered; Round 4 extractor proxy intact; parameterised Surreal queries.
