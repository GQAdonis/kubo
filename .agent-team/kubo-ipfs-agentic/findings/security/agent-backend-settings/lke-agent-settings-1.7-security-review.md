| L-1 | LOW | `lke-checks/agent-settings.sh`:87-99 | The checks for "admin has a file credential" and "admin has no subjects" grep the text that `yq -r` prints for a map. ## AGENTS.md rules

- **No tracking.** Nothing new reports out. `sub` is logged at Warn only on refusals (`jwt_session.go`:174, :190), as an operator-side security record.
- **Configurable endpoints and off switches.** `--agui` is the AG-UI switch. Removing `agui` from `routes` refuses session tokens there. `auth.oidc.enabled` turns off the verifier. Deleting the optional admin Secret disables admin (401 observed). No third-party service is enabled, since there is no `llm` block.
- **No silent CID injection.** N/A. No blockstore, pin or provide path changes. Chat writes still need the island interrupt; destructive tools are refused (`confirmation.modes: []`, `manifests.yaml`:1117-1119).
- **`/api/v0`, gateway, CID recipe, wire.** The `ipfs`, `ipfs-rpc` and `/api/v0` routes are unchanged. The image bump adds no RPC change.
