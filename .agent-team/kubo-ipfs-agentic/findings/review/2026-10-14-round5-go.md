## Findings

- **HIGH-1 (blocking): MFS walk not offline.** `index_bulk.go:358` `files/ls` with `offline: true` from `walkMFS` (`:353-388`); Kubo applies `offline` only in `GetApi` (`core/commands/cmdenv/env.go:42-55`); `files ls` uses `mfs.Lookup` and `Directory.List` (`core/commands/files.go:719-756`), and boxo v0.43.0 `ForEachEntry` fetches each child through the online `dagService.Get` (`boxo/mfs/dir.go:379-409`). A lazily copied directory makes bitswap requests; no per-call deadline, so the call can block holding the MFS directory lock; fetched blocks may be announced under `Provide.Strategy` `all`/`mfs`. Breaks tasks 1.1, 1.4, ADR-0011 V4, `docs/mcp/embeddings.md`. Tests miss it (`index_bulk_test.go:436-472` checks only the flag; CLI tests use local MFS or pins only). Fix in `mcp/server`: `files/stat --hash /` once, walk `/ipfs/<rootcid>/<rel>` with offline `ls`/`files/stat`, keep the path cursor; `test/cli` case with non-local `files cp` content asserting bounded completion, `not_local`, unchanged `refs local`.
- **MEDIUM-1: decision (1) ruled `describer_not_configured`.** `noMediaText` (`index_file.go:410-425`) falls through to `kind_not_enabled`; test `index_describer_test.go:383-387` pins it; `embeddings.md:312` vs `:365` disagree. Spec 1.6, the config schema off switch (`ipfs-mcp-config.schema.json:1014`) and the contract definition of `describer_not_configured` agree; the `kind_not_enabled` example in `ipfs_index_cid.output.json:31` is the outlier. Fix: return `describer_not_configured` for image/video when no stage ran; keep `kind_not_enabled` for the non-allowlisted binary case (`:244-252`); update test and docs; architect amends the contract example and `content-kinds.json` `notes.gating`.
- **MEDIUM-2: read-class status writes the store and races start/resume.** `currentRun` (`index_bulk_tools.go:96-109`) saves `paused` with an unlocked `active()` from `indexBulkStatus` (`:330`), `indexBulkCancel` (`:359`), `GET /index/status` (`index_routes.go:220`). Status can mark a live run `paused`; cancel vs resume can report success while the run continues. Fix: correct stale `running` only at startup and in `indexBulkStart` under `bulk.mu`; status projects without saving; cancel's load-check-save under `bulk.mu`.
- **MEDIUM-3: pin cursor per root pin.** `index_bulk.go:245-255`, `runs.go:44-51`: resume inside a pinned directory restarts it; non-indexed skips counted again and re-read, inflating counts and hitting caps early. Fix: cursor includes the path inside the pin; resume test pausing inside a pinned directory with unchanged counts.
