# Web UI review fixes, 2026-10-14

Phase `agent-backend-settings`, Round 4 correction cycle. Fork `GQAdonis/ipfs-webui`, uncommitted working tree.

Captured with headless Google Chrome driven over the DevTools protocol (no Playwright), against the CRA dev server (port 3199) and a temporary Kubo node (`IPFS_PATH` from `mktemp -d`, swarm 4199, API 5199, gateway 8199, empty bootstrap list, MDNS off, nothing on the default ports). The node holds 10 MFS entries (a folder, an empty folder, 6 text files, a 900 KB binary). It has no peers, so the Peers table shows its frame and headers with no rows. Tours off, language `en`. Dev server, node and Chrome were stopped by PID; ports 3199, 5199, 4199, 8199 and 9399 confirmed free.

WebMCP dialog: headless Chrome has no WebMCP, so the page was given a stub `document.modelContext` that records `registerTool`. The real app code then registered the tools; writes were turned on through the real Settings switch and the real `ipfs_add` tool was called, which opens the real confirmation dialog. Escape (a real key press) denied it and the dialog closed in every run.
