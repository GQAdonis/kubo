## Corrections to the #38 security read

- HIGH-1 cites "`flint-gate-config` `:1274-1275` (`base_url: http://kratos-admin:4434/`)". That line belongs to ConfigMap `kratos-config`: it is Kratos's own `serve.admin.base_url`. `flint-gate-config` names only `kratos-public:4433` (and `sso-broker:8080`). No workload calls Kratos admin today.
- So the 4433 allow list in task 5.5 (argocd-gateway proxies and kratos-ui) would have broken flint-gate's `kratos_session` provider and the sso-broker. #39 allows both.
